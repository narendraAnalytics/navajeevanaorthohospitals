  ---
  Two things to sort before deploying:
  1. Start command — Railway needs this. Create a Procfile in backend/:
  web: uvicorn app.main:app --host 0.0.0.0 --port $PORT

  2. ChromaDB ⚠️  — Railway has ephemeral storage (resets on redeploy). Your chroma_data/ folder won't survive. Two options:

  ┌──────────────────────────────┬─────────────────────────────────────────────────────────────────────────┐
  │            Option            │                                   How                                   │
  ├──────────────────────────────┼─────────────────────────────────────────────────────────────────────────┤
  │ Railway Volume (recommended) │ Add a persistent volume in Railway dashboard, mount to /app/chroma_data │
  ├──────────────────────────────┼─────────────────────────────────────────────────────────────────────────┤
  │ Re-seed on startup           │ Add seed_knowledge_base.py call to lifespan startup — runs every deploy │
  └──────────────────────────────┴─────────────────────────────────────────────────────────────────────────┘

  Re-seed on startup is the simplest — 7 docs seed in ~10 seconds.

  ---
  Env vars to set in Railway dashboard (copy from your .env):
  GROQ_API_KEY=gsk_...
  TAVILY_API_KEY=tvly-...
  NEON_DB_URL=postgresql://...
  CHROMA_MODE=local
  ALLOWED_ORIGIN=https://your-frontend.vercel.app
  APP_ENV=production
  LOG_LEVEL=INFO
